# take it eSee

Official take it eSee application.

## Production

Primary domain: https://takeitesee.com

The application is developed in `web/` and deployed through Vercel. The former standalone Coming Soon landing page has been retired from the active branch; its history remains available in Git.

## Development workflow

- `main` is the production branch.
- Feature work is developed and verified on feature branches before promotion to `main`.
- The public application is checked directly on `takeitesee.com` after production deployment.
