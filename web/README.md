TakeItEsee — web (development)

This folder contains the Next.js App Router starter scaffold for TakeItEsee.

Important notes
- This is a development scaffold only. Dependencies are NOT installed by this commit.
- Do NOT deploy or connect to Supabase until Phase 5 approval.

Local setup (run locally only)

1. Install dependencies:

```bash
cd web
npm install
```

2. Run development server:

```bash
npm run dev
```

3. Type-check and lint:

```bash
npm run type-check
npm run lint
```

4. Production build:

```bash
npm run build
```
