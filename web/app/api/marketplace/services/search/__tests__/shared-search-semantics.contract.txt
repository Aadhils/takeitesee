Shared Service search semantics contract

4. The same English and Tamil marketplace intent tokens are excluded from semantic service tokens for normal and nearby requests.
5. The shared semantic query is the canonical token array joined by a single space.
6. This refactor must not change category filters, availability filters, sort modes, ranking weights, pagination, geo matching, or API response shape.
7. Professional and Business Service discovery remains unified.
